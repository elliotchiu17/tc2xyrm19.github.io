ABOUT THIS ARCHIVE

不是要記住每一則新聞，
而是讓重要的事，不被時間沖淡。

資料整理僅供索引與個人研究。新聞內容與影片著作權屬原媒體；點擊標題可回到原始來源。自動蒐集可能遺漏報導，也不代表新聞內容已查證。

ARCHIVE MANAGER

ARCHIVE SETTINGS

搜尋與蒐集設定

編輯追蹤主題與媒體後，按「下載設定檔」。這個畫面不會直接改變公開網站；你需要將檔案放回 GitHub 的 data/config.json，再執行更新。

舊紀錄不會自動刪除。新增的媒體將透過 Google 新聞 RSS 搜尋；YouTube 與媒體官方 RSS 需要另外在 JSON 設定頻道或訂閱網址。修改名稱時，舊主題 ID 會盡量保留。
