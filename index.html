搜尋與更新方式

手動新增是主要功能。 自動搜尋只是補充，不會先按議員名稱、重要性或報導主題替「台中」篩掉新聞。

01　搜尋近期報導

點側邊欄「搜尋原始新聞」，以目前選取的關鍵字到 Google 新聞搜尋；也能自行在媒體網站搜尋後複製網址，再按「新增新聞」收錄。

02　自動追蹤（選用）

完整版 GitHub 專案附有自動更新工作流程，按設定週期查詢四組關鍵字及指定媒體；搜尋服務不一定收錄全部新聞，因此不能保證每天數十篇都抓齊。

03　永久保存手動編輯

在管理模式按「匯出資料」，把下載的 editorial.json 上傳到 Repository 的 data/editorial.json；只需上傳這個檔案，不必再改 HTML。

04　新增關鍵字／媒體來源

修改 GitHub 裡的 data/config.json：topics 管理主題名稱與搜尋字，sources 管理媒體名稱與網域。更改後重新整理網站，會顯示新設定。
